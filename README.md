# Dashboard de Gastos y Deudas Personales

Una aplicación web interactiva (Single Page Application) para llevar el control total de tus finanzas personales. Permite registrar gastos por categorías, visualizar resúmenes en gráficos dinámicos y llevar un registro detallado de las deudas (tanto dinero a favor como dinero a pagar).

##  Demo en Vivo
Puedes ver el proyecto funcionando aquí: https://squicciarinilautaro.github.io/dashboard-gastos-personales/

##  Características Principales
* **Gestión de Gastos:** Registro de movimientos con descripción, monto y categoría.
* **Cálculo Automático:** Sumatoria total del dinero gastado en tiempo real.
* **Visualización de Datos:** Gráfico de torta dinámico (Chart.js) que agrupa los gastos por categoría.
* **Gestión de Deudas:** Sistema inteligente de deudas que separa el dinero que debes del dinero que te deben, calculando totales independientes.
* **Persistencia de Datos:** Toda la información se guarda en la memoria del navegador (`localStorage`), por lo que no pierdes tus datos al recargar la página.
* **Diseño Responsive:** Interfaz adaptable a dispositivos móviles y computadoras de escritorio.

##  Tecnologías Utilizadas
* **HTML5** (Estructura semántica)
* **CSS3** (Flexbox, Media Queries, variables de estilo)
* **JavaScript Vanilla** (Manipulación del DOM, Web Storage API, métodos de Arrays)
* **Librerías externas:** Chart.js (Visualización de datos)
